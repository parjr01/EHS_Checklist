# EHS Site Visit Checklist & Executive Excel Dashboard

A mobile-responsive web application for conducting **EHS Site Visits** sorted by **Environment (E)**, **Health (H)**, and **Safety (S)** categories, with **Executive Multi-Tab Excel Dashboard export** and direct **OneDrive upload integration**.

---

## 🚀 Key Features & Flow

1. **Category Sorted View**:
   * 🌿 **Environment (E)** — 13 Checkpoints
   * 🩺 **Health (H)** — 21 Checkpoints
   * 🛡️ **Safety (S)** — 33 Checkpoints

2. **Executive Multi-Tab Excel Workbook**:
   * **Tab 1: 📊 Executive Dashboard & Pivot** (Metadata Block, KPI Scorecard Cards, Category Compliance Pivot Table).
   * **Tab 2: 🌿 Environment Checkpoints** (Forest Green Theme, status color fills).
   * **Tab 3: 🩺 Health Checkpoints** (Deep Purple Theme, status color fills).
   * **Tab 4: 🛡️ Safety Checkpoints** (Navy Blue Theme, status color fills).
   * **Tab 5: 📑 Master Audit Log** (All 67 Checkpoints with Auto-Filter).

3. **Strict Filename Convention**:
   * Exports strictly as: `site_date_membername.xlsx` (e.g. `PlantA_2026-08-03_RatneshPareek.xlsx`).

4. **Direct OneDrive Upload Integration**:
   * Header button and Next Step Modal link directly to the official Aditya Birla OneDrive Folder:
     `https://adityabirla-my.sharepoint.com/:f:/p/ratnesh_pareek/IgBUEAlv3EzjSIoJnIa9f7ZCAUvQ-bjzD2yY7QmIDwvMYUc?e=yfwRRD`
   * Clicking **Export Excel & Continue** automatically downloads the spreadsheet and opens the **Next Step** popup screen.

## 🛠️ GitHub Pages Deployment

1. Extract the codebase files (`index.html`, `app.js`, `styles.css`, `README.md`).
2. Upload the files to your GitHub repository.
3. Turn on **GitHub Pages** under repository **Settings** > **Pages** (`main` branch, `/ (root)` folder).
